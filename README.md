## 🏙️ About The Project

**ESTORA REALTY** is a modern real estate website designed to create a premium and engaging property browsing experience.

The interface combines clean layouts, property cards, smart filtering, interactive sections, responsive design and subtle visual effects to make property discovery simple and enjoyable.

The project was developed as a frontend-focused real estate experience using:

**HTML5 + CSS3 + JavaScript + Tailwind CSS**
